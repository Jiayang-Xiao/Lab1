# Lab1 · SVG 命令行编辑器

高级软件开发技术，Phase 1。使用 TypeScript、Command 与 Composite 实现六种 SVG 图形的编辑、持久化及撤销重做。

```powershell
npm ci
npm test
npm run cli
```

交互中输入 `help` 查看命令，输入结束（Ctrl+Z 后回车，或 Ctrl+D）退出。
示例回放：`npm run demo`。更多架构、语义决策、过程记录及验收依据见 [doc/README.md](doc/README.md)。
